Problem

Perception, memory, reasoning, and action — unified without the cloud.

Most cognitive robotics systems depend on cloud-based LLM inference, creating latency, privacy, and connectivity constraints that make real-world deployment impractical.

ARCHER addresses the challenge of integrating perception, memory, reasoning, and autonomous action into a single privacy-preserving robotic architecture with zero cloud dependency.

Architecture

Brain-to-Body: local reasoning meets real-time control.

ARCHER uses a two-layer architecture separating cognitive reasoning from real-time motor control:

  • Brain Layer: Local LLM reasoning via Ollama/Llama 3.2, voice input via Whisper, long-term memory via FAISS vector store, and speech synthesis via Piper
  • Body Layer: Real-time ROS 2 control using SLAM Toolbox, Nav2 navigation, and YOLOv8-nano for object detection
  • Command Bridge: A validated command parser with schema checks and safety supervision connects both layers reliably
  • Semantic Mapping: Persistent semantic map built from YOLOv8 detections annotated with spatial metadata
  • Hierarchical Planning: Task decomposition from natural language commands to Nav2 waypoints
