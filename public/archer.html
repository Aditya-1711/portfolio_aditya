Section 01 · Problem

Perception, memory, reasoning, and action — unified without the cloud.

Most cognitive robotics systems depend on cloud-based LLM inference, creating latency, privacy, and connectivity constraints that make real-world deployment impractical.

ARCHER addresses the challenge of integrating perception, memory, reasoning, and autonomous action into a single privacy-preserving robotic architecture with zero cloud dependency.

Section 02 · Architecture

Brain-to-Body: local reasoning meets real-time control.

ARCHER uses a two-layer architecture separating cognitive reasoning from real-time motor control:

Brain Layer

  • Language: Ollama / Llama 3.2 — fully local inference
  • Voice: Whisper STT, Piper TTS
  • Memory: FAISS vector store for episodic recall
  • Planning: Hierarchical task decomposition

Body Layer

  • Navigation: ROS 2, Nav2, SLAM Toolbox
  • Perception: YOLOv8-nano object detection
  • Mapping: Semantic map with spatial metadata
  • Safety: Schema-validated command parser
